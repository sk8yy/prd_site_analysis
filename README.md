## 交互调研网页

网页底图现使用本地缓存的 OpenStreetMap 真实底图；原始研究像素坐标通过可信港口锚点投影到该底图。该投影用于研究对照，不代表测量精度或真实航迹；底图署名为 OpenStreetMap contributors / ODbL。

直接在浏览器打开[web/index.html](web/index.html)，无需开发服务器。网页包括七组图层、中英文切换、地区及措施筛选、23项措施研判（展靓18、提质3、避让1、待研判1）、10项产品及组合线索、8组带简图的城市对、8道公共渡口候选和47条具名来源，以及PNG／SVG／PDF图件入口。底图和依赖均在本地，不会自动上传资料或请求远程地图；只有主动打开外部来源链接才访问对应网站。

交互图谱共81个点、12条线和20个面，跨图及点面存在重复，不是113处独立景点。绿色自然、蓝紫规划、橙色港区；橙虚线为港口临水观景界面，均不是法定界或航迹。使用图像坐标，不具备距离测量、地理定位或真实航迹功能。城市对高亮为所供底图内的沿湾研究区，不是完整行政区。产品状态区分现行目录、历史记录、公示及策划，不代表实时发班。

香港I·PARK按用户图示对象纠正为T·PARK邻近曾咀的 **I·PARK2（规划）**，移入规划专题；撤下此前误代入的石鼓洲I·PARK1点，保留第一期资料仅用于项目区分与南大屿生态背景。新增小虎岛文化组，以及华发冰雪世界、宝安深圳国际会展中心、深圳机场、前海石公园／桂湾、深圳湾公园五处展靓候选。海岛规划九组文化遗存对照见[补充研究](香港与水运补充研究.md)；金锁排、舢舨洲灯塔已列资源表，但准确定位未核，未强行落图。

名称已按用户更正为莲花山旅游区“望海观音”，另补黄山鲁森林公园；南沙生产港区与山体分开，文天祥纪念公园已撤下。公共渡运证据不证明非私有产权，8道候选渡口尚未进入严格产权筛选清单，也未强行落未经核准的登船坐标。

网页源模板为[web/index.template.html](web/index.template.html)，研究与来源数据为[research-data.json](research-data.json)。更新数据或模板后，在本目录运行以下命令重新生成网页：

```powershell
.\build-web.ps1
```

构建使用本地固定版本Leaflet 1.9.4、Lucide 0.468.0；缺少依赖时从jsDelivr下载，已有依赖按SHA-256清单核对。许可证与版本来源保存在web/vendor目录。脚本的CSP哈希随构建生成，不应直接修改生成的HTML。模板和数据内的文字通过文本节点展示；不使用账号、Cookie或访问密钥，也不处理证书。

既往界面验证记录：桌面1440×1000、手机390×844；图层数量、全部开关、检索无结果、详情联动、产品跳图和图件加载。本轮新增检查：I·PARK2规划单点检索、中英文状态、数据引用、静态图标签及五页PDF。内置浏览器实际视口为296×642，窄屏无横向页面溢出；请求的桌面尺寸未实际生效，因此不计作本轮有效桌面排版复验。地理准确性不属于上述界面测试结果。

## 修改与复现

点线配置见[map-data.json](map-data.json)，绘制脚本见[render-maps.ps1](render-maps.ps1)。点位xy采用2200×1893底图预览左上角起算的像素，不是经纬度。各图ID独立，不能直接替代六类资源清单的ID。

已将底图预览副本保存在[figures/basemap-reference.png](figures/basemap-reference.png)，原始JPEG未修改，也未上传。可从本目录运行以下命令重绘PNG和SVG；PDF需另行重新合订。

```powershell
.\render-maps.ps1 -Basemap '.\figures\basemap-reference.png'
```

## 制图约定

- 使用用户提供的260922会议底图，原图只读，不修改、不上传外部网站。
- 底图是无坐标说明的JPEG，先按海岸、河口与岛屿控制点检验定位。未取得原始GIS工程前，不作为精确测量成果。
- 区分坐标来源、底图匹配误差和资源状态；示意位置不等于精确码头入口。
- 城市景观增加面向水域的天际线岸段。地标存在、海上可见、游船实际经过分别核查，不把陆上观景点等同于船上视域。
- 运营产品区分近期官方发布、历史运营记录、现行产品介绍及规划意向。未完成实时售票核验的，不声称研究日正常发班。
- 航线图表达端点与公开途经景物支持的示意联系，不作为AIS航迹、航道、许可范围或导航依据。
- 用户底图不包含的资源不挤入图内，另列图外资源和延伸联系。
- 每张专题图附初步结论、证据及待验证问题；资源、产品和规划项目不混合统计。
