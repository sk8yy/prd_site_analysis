# 香港与水运补充研究：措施、供给缺口与规划范围

核查日期：2026年9月23日。进入[交互图谱](web/index.html)查看“措施研判”“游线供给”“城市对”和“资料来源”；下载[更新版五页图集](figures/PRD_Mapping_v02.pdf)。此稿补充原提资核读报告，不是现场调查或实时售票核验。

## 分析口径

以东岸及香港为重点，依次比较资源、旅游产品、城市公共空间（含规划）供给，识别三者之间的缺口，再提出景观及游线手法，并列出决策前必须核实的条件。没有客流和游客调查支持的“缺口”主要是供给衔接问题，不等于已经证明存在未满足的市场需求。

- **展靓**：成熟优质岸线、规划展示机会或合规低干扰保护展示，优先完善讲解与产品组织。流浮山、欢乐港湾等不因缺少套餐或尚未建成而归为提质。
- **提质**：存量遗存、停用设施或岸上游览链有明确改善线索。规划愿景未落实、步道状态未知、产品未打包，均不能单独作为提质依据。未核条件须保留，不能写成确定破败。
- **遮瑕／避让**：客观约束与拟议游览方式不相容时绕避或减扰。生产港区、生态岸线不因其类型而被判为“难看”。本轮没有充分船拍和现场依据，不能最终划定必须视觉遮挡的瑕疵岸段。
- **待研判**：缺关键到达、开放或许可证据，暂不强行归入三类。没查到班次不等于没有客观利用条件。

## 港区与轮廓

保留8处蓝紫规划面：南沙湾、威远岛、沙角、海洋新城、翠亨起步区、流浮山／尖鼻咀／白泥、SKYTOPIA机场城市、龙鼓滩。自然面绿色。新增4组橙色港区面及临水虚线：龙穴岛南沙港、大铲湾、赤湾—蛇口、葵青。港口远观界面不是安全距离、连续可视性、登岸权限或经营红线。

沿底图可辨岸形、岛岸和人工平台重描，取代规则少顶点包络；规划内陆边界、海岸公园水域外缘仍为示意。大铲湾点由水侧移至人工平台，蛇口点移至临港片区；南沙湾文化、山海、母港及规划代表点同步局部纠偏，航线端点随之更新。海鸥岛按官方岛屿相对关系重新辨识，北端被底图裁切。仍未完成GIS配准，不能声称全图无偏移。

范围按底图概化，只用于比较大片区与资源、水运的空间关系，**未经地理配准，不是规划红线、填海许可界、法定生态边界或批准用地**。面积不宜量算；面内可能包含既有资源，不代表全部新增。较小或缺少范围依据的任务继续仅标点。更准确的下一步是取得原始GIS或带坐标规划图后替换示意面。

现有图谱含81个点、12条线、20个面，存在跨专题及点面重叠，不是113个独立资源。另有8张城市对简图，高亮底图内的城市沿湾研究区，而非完整行政区。实线表示已获目录／班表联系，橙虚线表示售票及开航安排，灰虚线表示待核联系；全部不是航迹。静态图中文，网页中英文。

## 基层客运候选

[中山交通2025年12月报道](https://zsrbapp.zsnews.cn/home/content/newsContent/cp_3_30_1.htlass=/702599)明确8道在营渡口完成改造：沙口（小榄）、低沙（南头）、和泰（南头）、太丰、新丰、大茅、大滘、东罟。20艘渡船、1060客位及年均约500万人车次是综合渡运供给／人车统计，不是游客需求。

沙口位于小榄江滨公园北侧、联系小榄与东凤；低沙有示范改造与换船，和泰有智慧渡口系统。8道均进入公共客运候选表，但**非私有产权、2026许可、准确两岸登船点、坡道／浮趸尺度、旅游船兼靠及岸上公共路径未核**。因此没有宣称已完成严格“现状有条件、非私有、客运”的全部筛选，也不强行落图。下一步应向交通主管部门调取渡口档案、权属及许可，形成可用于空间研究的坐标清单。
