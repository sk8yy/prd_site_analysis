## 本轮已经改变的研究判断

1. 不能再概括为“跨市海上观光没有直接证据”。R01提供较新的穗深双向文旅产品证据；它是否形成稳定居民日常联动仍需班次、价格与客流验证。
2. 城市景观应增加“面向水域的天际线岸段”。R01已有珠海、澳门船上观赏的文字证据；深圳前海、蛇口、深圳湾须分段核实，不能把深圳全海岸均认定为可观天际线。
3. 现代工业景观已有产品使用。R03观看的是港区生产景观，不等于工业遗产开放参观；现代产业岸线与历史工业遗存应设两个副标签。
4. 观光线路到达、远观和经过是不同关系。R01报道中的珠海、澳门是景观对象，不据此登记为上下客停靠城市。
